# Facebook 主页运营细则

改编自 sergebulaev/facebook-skills（MIT）。"报告值"为社区实测，非 Meta 官方确认，用之前对照我们自己的数据。

## 一、排名信号（报告值）

| 信号                       | 影响 | 说明                                         |
| -------------------------- | ---- | -------------------------------------------- |
| 分享（到动态）             | 最高 | 帖子进入新的人群，是超过粉丝数的唯一自然办法 |
| 评论，尤其主页回复         | 最高 | 对话是最强的帖内信号                         |
| 评论串深度                 | 高   | 来回讨论说明有话题                           |
| 非"赞"的表情反应           | 中   | 比赞强，但对分发影响有限                     |
| 赞                         | 低   | 不当目标                                     |
| 链接点击                   | 中   | 带外链的帖子自然触达可能更低                 |
| 隐藏、少看、取消关注、举报 | 重罚 | 一次隐藏抵很多赞                             |

每条内容先定一个主要目标：分享 / 评论 / 反应。

## 二、短帖优先

报告值：**少于 80 字符的帖子互动高约 66%**。这是社区数据，不要当定律，先拿我们自己的数据验证。默认写短，写长是有意的选择；写长时第一行必须能撑起"查看更多"。

注意：我们的服务需要讲清楚流程，这种内容可以写长，但仍要第一行立住。

## 三、10 种公式（已按本站改写）

| 码   | 名称         | 目标 | 说明                                                   |
| ---- | ------------ | ---- | ------------------------------------------------------ |
| FB1  | 一句话观点   | 分享 | 一句可辩护的看法                                       |
| FB2  | 一个小数字   | 分享 | 一个具体数字改变看法。**数字必须真实**                 |
| FB3  | 向主页提问   | 评论 | 轻松、容易回答的问题（如"带孩子旅行，你最怕哪件事？"） |
| FB4  | 二选一       | 评论 | 友好的二选一，让人站队                                 |
| FB5  | 共鸣一句话   | 反应 | 一个具体的共同瞬间，不加铺垫                           |
| FB6  | 幕后         | 反应 | 业务里真实的人的一刻（涉及人要经其同意）               |
| FB7  | 实用小贴士   | 分享 | 一条能用、值得转发的建议                               |
| FB8  | 有转折的故事 | 分享 | 较长的真实故事。**不得编造**                           |
| FB9  | 有分量的公告 | 分享 | 新服务或新消息，用人话，不写"我们很高兴地宣布"         |
| FB10 | 客人聚焦     | 分享 | 展示真实客人。**必须有书面同意，不得伪造评价**         |

FB1–FB7 是短帖，FB8–FB10 是长帖。

## 四、规则

- 第一行承载整条帖子。
- 一帖一个想法。
- 话题标签 0–2 个，表情 0–2 个，严肃内容不放。
- **互动诱导**（"赞和分享""评论 YES""@3 个朋友"）会被降权。
- **外链**：自然触达可能下降。文字本身要能立住，不发光秃秃的链接；带链接时要给出引导语。
- **近似重复**的帖子（同一条换个说法）会触发相似惩罚。
- **原生视频**优先，不要链到 YouTube（也避开国内受限平台）。
- **图片和视频不能同时放进同一条帖子。**
- Facebook 允许纯文字帖，短文字帖常常是最好的形式。
- 不用"我们很高兴地宣布"这类企业自动驾驶式开头。
- 不要自动发布评论回复，见第六节。

## 五、主页优化（9 项评分）

| #   | 项目                | 通过标准                                                                                           |
| --- | ------------------- | -------------------------------------------------------------------------------------------------- |
| 1   | 行动按钮            | 设置并匹配目标。我们用 **联系我们 / 发消息**，对应"联系顾问咨询"；一个按钮一个任务，不要留默认     |
| 2   | 简介                | 服务谁 + 提供什么 + 一个具体事实；简短版放在卡片上，所以把最重要的放前面；完整版放所在地、联系方式 |
| 3   | 分类                | 最具体的准确分类，会解锁对应字段                                                                   |
| 4   | 主页名称            | 清晰的品牌名，可加搜索关键词；保持稳定，频繁改名会触发审核                                         |
| 5   | 用户名 / 自定义网址 | 认领 facebook.com/品牌名，短，与其他平台一致                                                       |
| 6   | 置顶帖              | 最能证明"关注后得到什么"的一条，匹配目标                                                           |
| 7   | 封面                | 一行价值主张，手机端可读，不要拼贴；留出手机裁切安全区                                             |
| 8   | 头像                | 品牌标识，小尺寸可辨认，对比度高                                                                   |
| 9   | 栏目与联系字段      | 把服务目标相关的栏目排前；网站、地址、电话、邮箱按分类填写；一个与目标匹配的链接                   |

两秒测试：只看主页名称、简介和行动按钮，陌生人会点击或关注吗？

## 六、评论回复（我们只能起草，不能自动发）

回复评论本身就是排名动作：第一小时回复快的主页，该帖触达更高。

原工具说明 Publora 没有 Facebook 评论接口。**我们也没有，所以每条回复都只给"可复制块"，由你在 Facebook 或 Meta Business Suite 里手动发。**

| 码  | 场景           | 写法                                                                                                                              |
| --- | -------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| C1  | 对方提问       | 直接回答 + 一个有用的具体细节，到此为止                                                                                           |
| C2  | 对方夸奖或补充 | 简短致谢 + 一条真正有价值的补充，不要光说"谢谢"                                                                                   |
| C3  | 对方投诉       | 先承认问题 → 承担自己的部分 → 给具体下一步 → 邀请私信。不辩解，**细节（订单号、联系方式、金额）只在私信里处理，不在公开评论里写** |
| C4  | 对方说好话     | 回一句让人愿意转发的话                                                                                                            |
| C5  | 对方分享经历   | 邀请其讲述；**未经其明确同意不得转为客人故事发布**                                                                                |

通用规则：短、人话、不用企业腔（"感谢您的宝贵意见"）；一个具体细节胜过三个泛泛的；回复里的服务、价格、时间必须是真的。

## 七、竞品与主页分析

数据来源：由你贴数字或截图。原工具用 Apify 抓取，暂不接入。

**主页读取**：名称、分类、粉丝数、赞数、简介、网站。
**评论读取**：把评论归成"提问 / 认同 / 反对"。反复出现的问题就是内容选题；有实质内容的评论是回复对象。按评论获得的反应数和回复数排序，找出自己传播起来的评论。

规则：

- Facebook 只显示反应数量，**看不到谁点了赞**。不要给出"点赞用户名单"。
- 粉丝数大小只是背景，先拿自己主页做对比再说"领先/落后"。
- 一个主题只有在多条评论里重复出现才算主题。
- 公开主页数据不等于私有洞察（没有触达、没有人口统计），不要当成 Meta Business Suite 数据。
- 不编造任何主页数据、粉丝数、评论、评论者名字。数据为空时直说并请你补充。

## 九、发布时间

原版给的是美国时间窗口（工作日 9–11 点、13–15 点），**不适用**我们跨时区的受众。以主页自带洞察为准，一周 4–7 条稳定节奏好过集中发。
