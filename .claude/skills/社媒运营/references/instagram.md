# Instagram 运营细则

改编自 sergebulaev/instagram-skills（MIT）。原文所有"报告值"都是社区实测，不是平台官方确认，下面标"（报告值）"的同理，用之前先对照我们自己的数据。

## 一、排名信号（报告值）

| 信号                     | 影响           | 对我们的意思                                   |
| ------------------------ | -------------- | ---------------------------------------------- |
| 发送给朋友 / 转发到快拍  | 最高           | 做"值得发给同行人"的内容：家人、一起旅行的朋友 |
| 收藏                     | 高             | 清单、行程框架、订房前要问的问题               |
| 评论（作者回复后更强）   | 高             | 真实问题，不是"你怎么看"                       |
| Reels 完播、重看         | 高（仅 Reels） | 前 1–3 秒定生死                                |
| 看主页后关注             | 高             | 主页要过关，见第四节                           |
| 点赞                     | 低             | 不当目标                                       |
| 不感兴趣、取消关注、举报 | 重罚           | 一次举报抵很多赞                               |

每条内容先选一个主要目标：收藏 / 发送 / 评论 / 关注，不要全都要。

## 二、三个"钩子位置"

- **文案钩子**：前约 125 个字符（折叠"更多"之前），必须自己能立住，不依赖第二行。
- **轮播第 1 张**：是承诺，不是标题。"5 件事"强过"小贴士"。第 1 张里放一个悬念（"多数人漏掉第 4 条"）。
- **Reels 前 1–3 秒**：画面 + 屏幕文字 + 第一句话。不要"大家好欢迎回来"。

## 三、10 种钩子公式（已按本站改写）

原版示例是"涨粉、月入、剪辑省时"，对我们不适用，这里只保留结构。**所有数字和事实必须来自站内核实内容或用户确认。**

| 码   | 名称               | 位置  | 目标       | 结构                                                                          |
| ---- | ------------------ | ----- | ---------- | ----------------------------------------------------------------------------- |
| IG1  | 数字领衔           | 文案  | 收藏       | 一个具体真实的数字 + 时间/范围 → "具体做法在下面"                             |
| IG2  | 反常识             | 文案  | 发送       | 大家都这么做 → 其实应该这样（须有事实支撑）                                   |
| IG3  | 共鸣瞬间           | 文案  | 评论       | 一个具体、人人经历过的瞬间，不加铺垫                                          |
| IG4  | 真实小故事         | 文案  | 评论、关注 | 时间点 + 发生了什么（含不顺的部分）+ 一句意义。必须真实，且涉及客人要经其同意 |
| IG5  | 清单轮播           | 轮播  | 收藏       | 第 1 张：N 件事 + 悬念；中间每张一条；末张回顾 + 收藏提示                     |
| IG6  | 前后对比           | 轮播  | 收藏、关注 | 第 1 张结果，第 2 张起点，中间步骤。**不得伪造客人案例**                      |
| IG7  | 破除误区           | 轮播  | 发送       | 误区 / 事实成对。误区必须是真有人这么想，不能稻草人                           |
| IG8  | 可套用框架         | 轮播  | 收藏       | 命名的框架，末张一张图总结（如"带孩子订酒店的 5 个问题"）                     |
| IG9  | 打断式 Reels       | Reels | 发送       | 第一帧文字提出主张，第一句直接进入重点                                        |
| IG10 | "我们怎么做" Reels | Reels | 收藏       | 第一帧点明结果，逐步展示，每步屏幕标注                                        |

选公式：先定目标，再看形式（单图 / 轮播 / Reels）。

- 一个结果、一个数字、一个瞬间 → 单图 + 文案（IG1–IG4）
- 一份清单 → 轮播 IG5；一个纠正 → IG7；一个框架 → IG8
- 动态、演示、现场 → Reels（IG9、IG10）

## 四、轮播结构

- 第 1 张是整个漏斗：不承诺就没人滑。
- 价值前置：最强的一条放第 2–3 张，滑动率随深度下降。
- 6–10 张为宜，每张只讲一个点、2 秒内读完，4:5 竖版。别为凑数灌水。
- 末张 = 一张图总结（值得收藏）+ **一个**行动（对我们就是三类行动之一）。
- 不要图片和视频混在同一个轮播里。

## 五、标签

- 3–5 个，不是 30 个。结构：2–3 个小众（少于 5 万帖）+ 1–2 个中等（5 万–50 万）+ 最多 1 个大词。
- 放文案末尾或首条评论。每个标签都要真的描述内容，别为了大流量乱加。
- 别每条都用同一组，按主题轮换。
- 不用互关类标签。
- 标签规模要在 App 搜索里看帖数，不要凭感觉。

## 六、主页优化（9 项评分）

关注的决定几乎全在主页顶部加前两三行九宫格上。

| #   | 项目     | 通过标准                                                                             |
| --- | -------- | ------------------------------------------------------------------------------------ |
| 1   | 头像     | 清晰、填满画面、小尺寸下可辨认（用品牌标识，不用未授权的第三方 logo）                |
| 2   | 名称栏   | 名称 + 人们会搜的关键词，30 字符内。**名称栏被搜索索引，用户名不是**                 |
| 3   | 用户名 @ | 短、好记、与品牌一致                                                                 |
| 4   | 简介     | 150 字符内：服务谁 + 做什么 + 一个具体事实。先写读者得到什么                         |
| 5   | 链接     | 一个，指向联系页或行程规划页，**不指向 Google 系服务**                               |
| 6   | 分类标签 | 商业/创作者账号设一个清晰分类                                                        |
| 7   | 精选     | 4–6 个，按访客下一个问题排序：开始 / 案例 / 服务 / 常见问题 / 关于，封面统一，名字短 |
| 8   | 前 9 格  | 整体一致、一眼可读、有范围感                                                         |
| 9   | 置顶     | 最多 3 条：一条最好的、一条服务说明、一条"这是为谁做的"                              |

检验方式："头部测试"：只看头像、名称、简介、链接和第一行九宫格，陌生人会关注吗？

## 七、周计划

默认支柱比例（可调）：教育 40% / 故事 30% / 互动 20% / 推广 10%。

- 每周 4–5 条正式内容 + 每天快拍；稳定节奏胜过日更灌水。
- 至少 2 条 Reels（拉新）、2 条轮播（收藏）、快拍每天 2–4 帧（含一次转发正式帖）。
- 至少 3 条收藏型（IG1、IG5、IG6、IG8、IG10）、2 条发送型（IG2、IG7、IG9）、1 条评论型、1 条真实故事。
- 同一公式一周不超过 2 次；单个支柱不超过一半；推广最多 1–2 条。
- 目标分布要均匀：收藏、发送、评论、关注。
- 发布时间：原版给的是美国时间窗口，**不适用**。我们的受众跨时区，以账号自带的洞察为准。

输出表：日期 / 形式 / 支柱 / 公式 / 一句话角度 / 目标 / 时间。

## 八、发布前清单

- [ ] 前 125 字符自己能立住
- [ ] 目标只有一个
- [ ] 标签 3–5 个且规模合理
- [ ] 表情 0–3 个，每个都有用意
- [ ] 轮播第 1 张有承诺和悬念，末张有总结和一个行动
- [ ] 图片尺寸 4:5 到 1.91:1，格式 JPEG / PNG，轮播 2–10 张且不混图视频
- [ ] 没有互动诱导（"评论 YES""双击""@3 个朋友"）：会被降权
- [ ] 没有别家 App 的水印
- [ ] 结尾是落点或具体提示，不是"你怎么看"
- [ ] 没有编造的数字、客人、评价
- [ ] 过了 `SKILL.md` 第六节的合规与调性检查

## 九、限制（参考）

文案 2200 字符；标签最多 30 个；轮播 2–10 张（App 内 20 张）；单图 ≤8MB；Reels 5–90 秒可进 Reels 页；每条必须带图或视频，纯文字帖不被接受。
